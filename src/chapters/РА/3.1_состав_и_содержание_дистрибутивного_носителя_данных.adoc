Дистрибутивный носитель содержит набор директорий с исходными кодами программных компонентов Системы, разработанных на языках JavaScript (NodeJS, React) и Java, Kotlin, а также вспомогательные конфигурационные файлы. Все компоненты предназначены для развертывания на технологических платформах серверов приложений и в кластере Kubernetes.

--
[.CustomList1]
--
admin-cms – модуль «Администрирование»: управление решениями, процесс изменения жизненных стадий публикаций;

semantic-topology – backend портала: интеграции, загрузка данных, сервисная логика.
--
[.CustomText]
В состав дистрибутива включается полный файл конфигурации пайплайна GitLab CI/CD: .gitlab-ci.yml – конфигурация автоматизированного процесса сборки, тестирования и развертывания компонентов, включая стадии debug, prepare, build, deploy в окружения Dev, Test, Stage и Prod.
