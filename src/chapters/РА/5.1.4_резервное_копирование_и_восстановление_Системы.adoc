Резервное копирование компонентов промышленной среды рекомендуется выполнять с учетом особенностей используемой технологической платформы. Контейнерная инфраструктура Kubernetes, виртуальные машины и объектное хранилище S3 резервируются средствами эксплуатационных служб, обеспечивающих создание и хранение копий на уровне инфраструктуры.

Для реляционных данных, размещенных в PostgreSQL, рекомендуется применять встроенные механизмы резервного копирования (pg_dump) с выполнением полной ежедневной копии и хранением WAL журналов в соответствии с политикой восстановления.

Топики Kafka не требуют резервного копирования, поскольку не содержат данных, критичных для восстановления бизнес функционала; при их потере система уведомлений может быть восстановлена без влияния на целостность пользовательских данных.

Подробнее резервное копирование описано в документе «Описание архитектуры системы» (ххх).
